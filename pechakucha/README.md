# Criminal Mind PechaKucha

Builder page and assets for a 10-slide, 20-seconds-per-slide talk on forensic psychology.

- `deck.json`: words, script and source notes per slide
- `index.src.html`: the builder page; `build.py <photo folder>` writes `index.html` and `img/`
- `output/`: the PowerPoint and script built with the default choices
